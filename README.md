# walker-lane-tactics-jiean-yin

**Assignment 2 — Generate Art, Sound, and Music for Your Game · Jiean Yin · Godot 4.7.2**

*Lane Tactics* (working title): a turn-based, simultaneous-orders tactics game. Carved wooden pieces fight on a five-lane tabletop board, and you win by standing a piece on the enemy's back row. This repository holds the design and the asset slice; the full game is this semester's project.
